# Data

`airfoil_self_noise.dat` is the Airfoil Self-Noise data set of the UCI Machine Learning Repository, unmodified:
1503 rows, six tab-separated columns without a header.

| Column | Variable | Unit |
|---|---|---|
| 1 | frequency | Hz |
| 2 | angle of attack | degrees |
| 3 | chord length | m |
| 4 | free-stream velocity | m/s |
| 5 | suction-side displacement thickness | m |
| 6 | scaled sound pressure level (the response) | dB |

Source: Brooks, T., Pope, D. and Marcolini, M. (1989). Airfoil Self-Noise [Dataset]. UCI Machine Learning
Repository. <https://doi.org/10.24432/C5VW2C>. The measurements are from NASA wind-tunnel tests of NACA 0012
airfoils (T. F. Brooks, D. S. Pope and M. A. Marcolini, *Airfoil self-noise and prediction*, NASA Reference
Publication 1218, 1989).
